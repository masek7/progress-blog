## O que é um Logaritmo?

Logaritmos são o oposto de exponenciais. Básicamente no log₁₀(100) = 2, Dizemos: Quantos 10's conseguimos multiplicar para chegar a 100?
Se `b^x = y`, então `log_b(y) = x`

## Exemplos

- log₂(8) = 3  →  porque 2³ = 8
- log₁₀(100) = 2  →  porque 10² = 100

## Em Python

```python
import math

print(math.log2(8))    # 3.0
print(math.log10(100)) # 2.0

```
